# 未決定事項

以下は実装に着手する前、または該当機能に入る前に確定が必要です。

| 項目 | 現状 | 影響範囲 |
| --- | --- | --- |
| 認証・利用者識別 | 未決定 | API、DB、同期対象の分離 |
| 同期の競合解決 | optimistic concurrency を候補とする | API、UI、再試行 |
| 同期起動 | PoCでは手動ボタンを採用。アプリ起動・ネットワーク復帰時の自動同期は未決定 | MAUI のライフサイクル設計 |
| 削除済みデータの保持期間 | 未決定 | PostgreSQL / SQLite のクリーンアップ |
| API と DB の起動方式 | Docker Compose を候補とする | 開発環境・CI |
| Java / .NET のバージョン | 未決定 | テンプレート・CI |
| iOS 実機での同期先到達性 | 未決定 | HTTPS、ネットワーク構成 |

## 推奨する初期決定

- Java 21 LTS、Spring Boot 3 系、PostgreSQL 16、.NET 8 LTS または採用時点のサポート中 LTS を使用する。
- 開発時の PostgreSQL は Docker Compose で起動する。
- 同期はまず手動ボタンで始め、成功・失敗・未同期件数を画面に表示する。
- 競合は `version` による検出までを PoC の必須範囲とし、解決 UI は後続検討にする。
